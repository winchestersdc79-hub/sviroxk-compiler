# SC

SC — самостоятельный универсальный язык программирования в разработке. Компилятор написан на C++ и использует LLVM для генерации машинного кода. Исходные файлы пока сохраняют совместимое расширение `.svx`.

## Цель

Цель проекта — постепенно создать самостоятельный универсальный язык, компилятор, стандартную библиотеку и инструменты для приложений, серверов, системного ПО, автоматизации и инструментов разработчика. Игры и игровой движок не входят в цели проекта. SC пока является ранним прототипом, а не законченным языком для больших проектов.

## Этапы разработки

- **Этап 1 — Компилятор на C++** (текущий) — лексер, парсер, LLVM, синтаксис из README
- **Этап 2 — Самохостинг** — компилятор на SC
- Разработка игр и игрового движка не планируется.

Подробный чеклист: [STATUS.md](STATUS.md)

## Синтаксис

Новый короткий синтаксис поддерживается параллельно с прежними конструкциями для совместимости:

```sc
fn add(int left, int right) {
    return left + right;
}

let answer: int = add(20, 22);
print(answer);
```

Файлы исходников пока используют расширение `.svx`.

### Переменные
svi rox lor x = 5;
svi dor lor y = 3.14;
svi cos lor name = "SC";
svi bue lor flag = true;
### Массивы
svi rox[] lor arr = [1, 2, 3];
slov(arr[0]);
### Объявление функций и процедур

Функции без аннотации результата возвращают `int`. Для других результатов указывается тип перед именем: `fn float scale(...)`. Процедура без результата объявляется явно как `fn void announce(...)`; только такие процедуры могут завершаться без `return`.

### Проверка типов

Перед генерацией LLVM SC проверяет типы простых переменных, арифметики, присваиваний, аргументов функций, структурных полей, массивов и `return`. Неявно разрешены `int` → `float` и целочисленные варианты в `rox64`; остальные числовые преобразования задаются явно. Ошибки семантики печатаются как `файл:строка:столбец: error[semantic]` и останавливают генерацию кода.

Пока не поддерживаются полноценный вывод типов, области видимости блоков с затенением, `null`, перечисления, обобщения, доказательство возврата по всем веткам и продолжение после нескольких синтаксических ошибок. Проверка `break`/`continue` действует для циклов; указатели пока представлены общим типом `ptr`.

### Импорты

Пути модулей разрешаются относительно файла, который содержит импорт. Вложенные импорты поддерживаются; повторные импорты загружаются один раз, циклы и отсутствующие файлы завершаются диагностикой.

```sc
imp "lib/math.svx";
```

### Условия
eles (x > 5) {
slov("больше");
} sele {
slov("меньше");
}
### Циклы
cert ceh (10) {
slov("повтор");
}
cert usy (x < 10) {
x = x + 1;
}
### Функции
fucn add(rox a, rox b) {
rev a + b;
}
svi rox lor result = cop add(5, 3);
### Операторы

Символы как везде: `+` плюс, `-` минус, `*` умножение, `/` деление.  
Приоритет: сначала `*` и `/`, потом `+` и `-` (как в C и Python).

### Структуры
tip Player {
    rox health = 100;
    rox speed = 5;
}
svi tip Player lor hero;
hero.health = 80;
slov(hero.health);
svi tip Player lor bot = { health = 50; speed = 3; };
fucn dor avg(rox a, rox b) {
    rev (a + b) / 2;
}
### Указатели
svi rox lor x = 5;
svi ptr lor p = &x;
*p = 10;
slov(*p);
### Файлы
svi file lor f = atk("file.txt");
zap(f, "текст");
zak(f);

## Сборка компилятора

```bash
chmod +x build.sh run.sh   # один раз, если Permission denied
./build.sh
# или:
clang++ main.cpp lexer.cpp parser.cpp semantic.cpp codegen.cpp \
  -I/path/to/llvm/include \
  $(llvm-config --cxxflags --ldflags --libs) \
  -fexceptions -o sc
```

### Запуск программы

```bash
./run.sh hello.svx         # сборка + запуск через компилятор sc
# или вручную:
./sc program.svx > output.ll
llc output.ll -o output.s
clang output.s -o program -lm
./program
```
