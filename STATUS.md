# SC — статус разработки

SC находится на ранней стадии разработки. Наличие работающего прототипа компилятора не означает, что язык, стандартная библиотека или инструменты готовы для крупных проектов. Разработка игр и игрового движка не входит в цели проекта.

## Сделано

- Generated ARM64 binaries, object files, LLVM/assembly output and empty build log removed from Git tracking; `.gitignore` now excludes local build products. `test.svx` retained as an actual source regression fixture; stale `test` executable and unreferenced `test.txt` removed.

| Область | Статус |
|---------|--------|
| Лексер + номера строк в ошибках | ✅ |
| Операторы `+ - * /` с обычным приоритетом | ✅ |
| Переменные, массивы, условия, циклы, функции | ✅ |
| Указатели, файлы, импорт, ввод/вывод | ✅ |
| Структуры + `p.field` | ✅ |
| Инициализация: `svi tip Player lor p = { health = 80; };` | ✅ |
| `fucn dor имя(...)` — возврат `dor`/`cos`/и др. | ✅ |
| Типы параметров в `fucn` | ✅ |
| `rep()`, `test.sh` | ✅ |

## Следующие направления

- [~] Скалярные типы и алиасы `int/i32`, `uint/u32`, `short/i16`, `ushort/u16`, `long/i64`, `ulong/u64`, `byte/u8`, `float/f32`, `double/f64`; прямые литералы проверяются по диапазону, явные скалярные casts проходят runtime-тесты. `i8/i16` продвигаются до i32, `u8/u16` до u32; mixed signedness от 32 бит отклоняется. Decimal/exponent float literals поддержаны и покрыты runtime-тестами. Точные массивы/поля структур отклоняются; pointer/heap array path остаётся i32; runtime overflow checks ещё нет.
- [ ] Устойчивое дерево синтаксиса и диагностические сообщения
- [~] Первый семантический проход проверяет имена, повторные объявления, типы переменных/аргументов/возвратов, арифметику, массивы, структуры, управление циклом и прямые ветки if/else; сложный анализ потоков управления, вложенные пути возврата и полная система типов ещё не готовы. Неаннотированные функции возвращают int; процедуры объявляются как fn void.
- [x] Разрешение вложенных относительных импортов, дедупликация и выявление циклов; пространства имён и изоляция модулей пока не реализованы
- [~] Начальный source module `math` в `stdlib/math/math.svx`: `math_abs`, `math_min`, `math_max`, `math_is_even` проверены через относительный file import и запуск. `use math`/qualified calls пока не поддержаны; большая часть стандартной библиотеки и модель управления памятью отсутствуют
- [ ] Самохостинг компилятора на SC
- [ ] Инструменты редактора, включая VS Code, после стабилизации языка

```bash
./test.sh          # все примеры

```
